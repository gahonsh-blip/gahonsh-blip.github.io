How to Apply Changes to Live Website

Since Gahonsh is hosted on GitHub Pages, changes become live as soon as the edited file is committed to your GitHub repository.

Quick Method (No Terminal Required):
  1. Edit your page in the Live Page Editor tab.
  2. Click the green "Download File" button (e.g. index.html).
  3. Open your GitHub repository in your browser: github.com/gahonsh-blip/gahonsh-blip.github.io
  4. Click Add file → Upload files, drop your downloaded file, and click Commit changes.
  5. Within 30-60 seconds, your live website automatically updates worldwide!
Direct Copy-Paste Method:
  1. Click "Copy Code" in the dashboard.
  2. Open that file on GitHub.com and click the Pencil icon (Edit file).
  3. Select all (Ctrl + A), paste the new code (Ctrl + V), and click Commit changes.
