GAHONSH · sales pipeline

Find the gap, ask first, quote later.

A local, idempotent pipeline that finds small businesses with a weak web presence, scores them with explainable points, and writes a consultation-first draft. It never sends email and never builds a website on its own.

1 · Discover

Places search per city and category, deduplicated by place id.

2 · Audit

Reachability and mobile friendliness, recorded as evidence.

3 · Score

Every point carries a reason, so the draft can cite it.

4 · Draft

sent: false and requiresApproval: true. No send path exists.
